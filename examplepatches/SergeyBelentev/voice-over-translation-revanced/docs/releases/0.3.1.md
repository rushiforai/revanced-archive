Исправлено отсутствие экранной клавиатуры при входе в Яндекс ID. Окно WebView теперь разрешает ввод в поля страницы после её загрузки.

### Скачать и установить

Основной способ: **ReVanced Manager → Патчи → добавить → удалённый источник / URL**. Вставьте:

```text
https://raw.githubusercontent.com/SergeyBelentev/voice-over-translation-revanced/main/patches.json
```

Можно включить автообновление набора. Если VOT уже импортирован локально, удалите старый локальный набор, сохранив официальный источник ReVanced.

Альтернатива: скачайте **vot-standalone-0.3.1.rvp** из **Assets** ниже и импортируйте как локальный набор. Выберите один способ, чтобы VOT не дублировался.

**[Актуальная инструкция установки](https://github.com/SergeyBelentev/voice-over-translation-revanced/blob/main/docs/INSTALL.md)**

Проверяемая связка: **YouTube 20.40.45 + официальные ReVanced Patches 6.2.1 + Manager 2.6.0**. В `.rvp` только патч **Add VOT (voice-over translation)**. Применяйте его со стандартным официальным набором за один проход к **чистому APK**.

При обновлении обновите удалённый источник либо замените прежний локальный набор VOT, пересоберите APK и установите его через тот же Manager. Обновление набора само по себе не обновляет установленный YouTube.

### Управление

- Нажать **VT** — включить/выключить перевод.
- Удерживать **VT** — языки, отдельные громкости и автоперевод.
- Только перевод: оригинал **0%**, перевод **100%**, **Сохранить**.
- Живые голоса: **Настройки → ReVanced → VOT — Живые голоса**, вход в Яндекс; перевод на русский.
