# Установка VOT 0.3.1

Инструкция для **ReVanced Manager 2.6.0**, официальных **ReVanced Patches 6.2.1** и **YouTube 20.40.45**. Названия элементов интерфейса зависят от языка Manager.

Основной способ — добавление по URL: Manager сам скачивает набор и может проверять его обновления. Локальный импорт `.rvp` остаётся альтернативой.

## 1. Подготовка

- Для установки по URL скопируйте адрес источника из следующего раздела. Для локального импорта скачайте **[vot-standalone-0.3.1.rvp](https://github.com/SergeyBelentev/voice-over-translation-revanced/releases/download/v0.3.1/vot-standalone-0.3.1.rvp)** из **Assets** на странице релиза. Архивы **Source code** для установки не нужны.
- Подготовьте **чистый, ещё не пропатченный APK YouTube 20.40.45**, подходящий устройству. Нужен одиночный `.apk`, а не контейнер `.apkm`, `.apks` или `.xapk`.
- Убедитесь, что официальный источник в Manager использует патчи **6.2.1**. Установка самого нового набора другой версии не гарантирует совместимость.

Файл `.rvp` не открывается как приложение Android: его импортируют в Manager. APK YouTube в этом проекте не распространяется.

## 2. Добавьте VOT в Manager

### По URL — основной способ

```text
https://raw.githubusercontent.com/SergeyBelentev/voice-over-translation-revanced/main/patches.json
```

1. Откройте раздел **Патчи**, нажмите кнопку добавления (при необходимости **✏️ → +**).
2. Выберите **удалённый источник / URL**, вставьте адрес целиком и подтвердите добавление.
3. По желанию включите автоматическое обновление источника. Manager сам скачает `.rvp`, указанный в JSON.
4. Если VOT ранее добавлен локальным файлом, удалите старый локальный набор. Оставьте один источник VOT и официальный источник ReVanced **6.2.1**.
5. Продолжите сборку по следующему разделу.

Ссылка указывает на JSON в raw-формате. Страница GitHub, ссылка `/blob/…/patches.json` или прямая ссылка на `.rvp` для этого поля не подходят. Обновление набора в Manager не обновляет установленное приложение автоматически.

### Локальным файлом

1. Откройте раздел **Патчи** со списком источников / наборов патчей.
2. Если там уже есть старый VOT, удалите **только этот набор**. Официальный источник ReVanced сохраните.
3. Нажмите кнопку добавления набора (в интерфейсе 2.6.0 она может открываться через кнопку редактирования **✏️ → +**).
4. Выберите **локальный источник** / импорт файла, затем скачанный `vot-standalone-0.3.1.rvp`. Подтвердите добавление.
5. Проверьте, что у нового набора версия **0.3.1** и один патч: **Add VOT (voice-over translation)**.

Выберите один способ добавления: URL или локальный файл, чтобы VOT не дублировался.

## 3. Соберите приложение

1. В разделе приложений / патчера выберите APK **из хранилища** и укажите чистый YouTube **20.40.45**.
2. Откройте выбор патчей. Если он заблокирован, в настройках Manager → **Меры предосторожности** включите **Разрешить изменение выбора и параметров патчей**.
3. Оставьте **стандартный выбор официальных патчей ReVanced 6.2.1**. Не включайте все необязательные патчи подряд.
4. Дополнительно отметьте **Add VOT (voice-over translation)** из добавленного источника VOT (удалённого либо локального).
5. Убедитесь, что выбран **Remove background playback restrictions**, необходимый для работы с выключенным экраном.
6. Запустите применение. Официальные патчи и VOT должны применяться **вместе за один проход**.
7. После успешной сборки нажмите **Установить**. Если приложение запросит ReVanced GmsCore, выполните его инструкцию по установке.

Не используйте уже установленный / ранее пропатченный ReVanced APK как основу для добавления VOT. Каждый раз собирайте приложение заново из чистого APK.

## 4. Включите перевод

1. Откройте обычное видео и покажите элементы управления плеером.
2. Нажмите кнопку **VT**: начнётся подготовка перевода. Повторное короткое нажатие выключает VOT.
3. Для выбора языка **удерживайте VT**. По умолчанию оригинал — английский (`en`), перевод — русский (`ru`). Изменения подтвердите кнопкой **Сохранить**.

Сервису может потребоваться время на подготовку полной дорожки. Перевод недоступен для Shorts и прямых эфиров.

## Громкость оригинала и перевода

**Долгое нажатие VT → Громкость оригинала / Громкость перевода → Сохранить.**

Для просмотра только с переводом выставьте **оригинал 0%**, **перевод 100%**. Системная громкость устройства влияет на оба звука. Пока перевод готовится, во время перемотки и после выключения VOT оригинал возвращается к обычной громкости YouTube.

В этом же окне можно включить автоматический перевод следующих видео.

## Живые голоса

1. Откройте **Настройки YouTube → ReVanced → VOT — Живые голоса**.
2. Нажмите **Войти в Яндекс**. В открывшемся окне Яндекс ID нажмите поле логина и войдите в аккаунт; при необходимости подтвердите доступ для приложения VOT.
3. После сообщения об успешном входе включите **Живые голоса**.
4. Удерживайте VT в плеере и убедитесь, что язык перевода — **ru**. Язык оригинала выбирается вручную.
5. Включите перевод коротким нажатием VT.

Обычные голоса не требуют входа. Доступность живых голосов зависит от сервиса Яндекса и аккаунта. При смене голоса или языка активный перевод перезапускается. Если токен истёк или отклонён, войдите снова.

Кнопка выхода удаляет аккаунт из VOT и выключает живые голоса. Она не завершает сессии Яндекса в других приложениях и не очищает cookies страницы входа.

## Фоновая работа

В настройках YouTube разрешите фоновое воспроизведение. После начала перевода выключите экран и проверьте воспроизведение, паузу и возобновление из уведомления. VOT следует позиции, скорости и состоянию аудиовыхода YouTube; если сам YouTube остановлен, перевод тоже приостанавливается.

## Обновление VOT

1. Обновите удалённый источник VOT в Manager либо замените старый локальный набор новым `.rvp`.
2. Повторно примените официальный стандартный набор и новый VOT к **чистому APK** поддерживаемой версии.
3. Установите результат поверх предыдущего приложения, используя тот же ключ подписи Manager.

Сам импорт нового `.rvp` не меняет уже установленное приложение. Если Android сообщает о конфликте подписи, нужен прежний ключ Manager. Не удаляйте установленное приложение без сохранения нужных данных: удаление сбросит его локальные настройки и вход VOT.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Нет кнопки VT | Патч VOT выбран, оба набора применены вместе, открыто обычное видео и показаны элементы плеера |
| Клавиатура не появляется при входе | Приложение действительно пересобрано с **0.3.1**; закройте и снова откройте окно входа |
| Нет пункта живых голосов | Откройте именно настройки **ReVanced**, проверьте версию использованного VOT |
| Просит войти повторно | Откройте раздел живых голосов и выполните вход заново |
| Слышен оригинал | Оригинал **0%**, нажата **Сохранить**, перевод уже начал воспроизводиться |
| Перевод останавливается при блокировке | Выбран патч фонового воспроизведения, фоновое воспроизведение разрешено в YouTube, само видео продолжает играть |
| Сбой приложения / ошибка применения | Использованы YouTube **20.40.45**, официальные патчи **6.2.1**, один набор VOT **0.3.1**, чистый исходный APK |

Если ошибка сохраняется, [создайте issue](https://github.com/SergeyBelentev/voice-over-translation-revanced/issues) с версиями Android, YouTube, Manager и патчей, шагами воспроизведения и текстом ошибки. Удалите из прикладываемых логов пароли, OAuth-токены и личные данные.
