# Sources and licenses

This is an experimental, independently written ReVanced integration, not an official ReVanced or VOT release.

Integration and tests are distributed under GNU GPL version 3, matching the ReVanced repository. The accompanying `VOT-LICENSE-GPL.txt` contains its text. The VOT protocol port retains the MIT notice in `VOT-LICENSE-MIT.txt`.

Protocol references:

- https://github.com/ilyhalight/voice-over-translation — commit `7a823f11430581c47bf8090aacb588b44b3799bb`, MIT.
  OAuth callback handling follows `src/core/auth.ts` and the callback origin in `src/config/config.ts`. The public client ID is from the redirect returned by upstream's `/v1/auth/handle` endpoint. This integration uses that VOT OAuth application with an independently generated state and intercepts the callback before loading its page.
- https://github.com/FOSWLY/vot.js — commit `b058bb0de80641a47e5eacda04328625d54c2f5c`, version 3.1.1, MIT, Copyright (c) 2024 FOSWLY. The native request fields, session/signature construction and no-client-audio fallback follow `packages/core/src/protobuf.ts`, `packages/core/src/providers/yandex.ts`, `packages/shared/src/secure.ts`, `packages/shared/src/protos/yandex.proto` and `packages/shared/src/data/config.ts`.

ReVanced reference/base:

- https://gitlab.com/ReVanced/revanced-patches — commit `015fe10a23ea5b919a3fda6e7da2c176517ae75d`, GPL-3.0. Existing video-information, background-ID, player-control and instruction-transformation APIs are reused. The button host layout follows the structure of the existing Copy video URL patch.

Protocol checks use reference bytes generated by the original published `@vot.js/shared@3.1.1` protobuf encoder. Standalone Android compilation uses Google's API 34 SDK stubs; SDK files are not included in this distribution. The standalone packaging, separate extension, API validation and player integration were revised on 2026-09-25. Only the VOT add-on is shipped; the official 6.2.1 bundle is used externally for integration testing.

This repository distributes the independent integration and its source code. Upstream repositories, YouTube APKs, official ReVanced bundles and service credentials are not included.
