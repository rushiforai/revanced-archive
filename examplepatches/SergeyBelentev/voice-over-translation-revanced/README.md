# VOT для YouTube ReVanced

Закадровый перевод видео через Яндекс: обычные и **«Живые голоса»**, отдельная громкость оригинала и перевода, синхронизация с плеером и фоновое воспроизведение.

Независимая интеграция [voice-over-translation](https://github.com/ilyhalight/voice-over-translation) / [vot.js](https://github.com/FOSWLY/vot.js) в Android-приложение YouTube. Это не официальный проект ReVanced, VOT или Яндекса.

**[Установка по URL](docs/INSTALL.md#2-добавьте-vot-в-manager)** · [JSON-источник для Manager](https://raw.githubusercontent.com/SergeyBelentev/voice-over-translation-revanced/main/patches.json) · [Скачать .rvp вручную](https://github.com/SergeyBelentev/voice-over-translation-revanced/releases/download/v0.3.1/vot-standalone-0.3.1.rvp) · [Все релизы](https://github.com/SergeyBelentev/voice-over-translation-revanced/releases)

## Совместимость

| Компонент | Проверяемая версия |
| --- | --- |
| YouTube | **20.40.45**, чистый APK |
| Официальные ReVanced Patches | **6.2.1**, стандартный выбор |
| ReVanced Manager | **2.6.0** |
| VOT | **0.3.1** |

В `.rvp` находится только один выбираемый патч: **Add VOT (voice-over translation)**. Его нужно применять вместе с официальными патчами за один проход. Совместимость с RVX, другими версиями YouTube и произвольными наборами патчей не подтверждена.

## Быстрая установка

Основной способ установки — добавить в Manager **удалённый источник** по этой ссылке:

```text
https://raw.githubusercontent.com/SergeyBelentev/voice-over-translation-revanced/main/patches.json
```

1. В разделе патчей нажмите **добавить → удалённый источник / URL**, вставьте ссылку выше и подтвердите добавление. Можно включить автообновление набора.
2. Сохраните официальный источник ReVanced **6.2.1**. Предыдущий локальный набор VOT удалите, чтобы не применять VOT дважды. Альтернатива URL — импорт `.rvp` из [релиза](https://github.com/SergeyBelentev/voice-over-translation-revanced/releases/tag/v0.3.1).
3. Выберите **чистый APK YouTube 20.40.45**, оставьте стандартные официальные патчи и дополнительно включите **Add VOT (voice-over translation)**.
4. Примените патчи и установите APK через Manager.

Подробности, обновление и решение проблем: **[docs/INSTALL.md](docs/INSTALL.md)**. Готовый YouTube APK в релиз не входит; `.rvp` — набор патчей, а не устанавливаемое Android-приложение.

Обновление источника загружает набор в Manager. Уже установленный YouTube обновляется только после повторной сборки и установки APK. Для сопровождающего проекта: [как обновлять URL-источник](docs/SOURCE.md).

## Управление

| Действие | Где настроить |
| --- | --- |
| Включить / выключить перевод | Короткое нажатие **VT** в плеере |
| Языки, громкости, автоперевод следующих видео | Долгое нажатие **VT** |
| Только перевод, без оригинала | Оригинал **0%**, перевод **100%**, затем **Сохранить** |
| Живые голоса и вход в Яндекс | Настройки YouTube → **ReVanced → VOT — Живые голоса** |

Для живых голосов войдите в Яндекс и выберите перевод на русский (`ru`). Обычные голоса работают без входа. Для работы с выключенным экраном нужны официальный патч **Remove background playback restrictions** и разрешённое фоновое воспроизведение в YouTube.

## Ограничения и данные аккаунта

Поддерживаются обычные видео до 4 часов. Shorts, прямые эфиры, Chromecast и субтитры не реализованы. Перевод запускается после получения полной аудиодорожки; ожидание ограничено 20 минутами. При ожидании, перемотке или выключении VOT восстанавливается обычная громкость оригинала.

Используется неофициальный протокол Яндекса, который может измениться. Вход выполняется через публичное OAuth-приложение исходного VOT. Токен хранится локально с шифрованием Android Keystore и передаётся API Яндекса только для живых голосов. Пароль обрабатывает страница Яндекса. Истёкший токен требует повторного входа.
