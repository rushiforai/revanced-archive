# chmate-revanced v1.2.5

Issue #16の画像表示、上部広告の空白、画像掲示板の操作導線を修正するリリースです。変更内容はCHANGELOGの同版の項目を公開workflowで本文へ取り込みます。

## 画像掲示板の使い方

「設定」下部の「画像掲示板の板」でHTTPSの板またはスレッドURLを保存し、下の「板を開く」ボタンを押します。ホームの板一覧へ追加する場合は、「掲示板・BBSMENU」（旧版は「掲示板設定」）で「板一覧を取得/更新」を実行してください。

`https://sportschan.org/librejp/thread/16592.html`のようなjschanスレッドURLは、登録前でもChMateの「URLを開く」から直接開けます。サイトが公開するJSON APIを使うため、非公開・削除済み・API非対応のスレッドは取得できません。

## 公開前検証

承認を得てAQUOS SH-R80P / Android 16のChMate 0.8.10.246 devへデータを保持して更新し、ホーム・設定と子画面・追加画面、画像表示、更新、同一スレッドの20回連続開閉を検査しました。検査後のFATAL EXCEPTIONは0件です。上部広告Viewは同じ5chスレッドで高さ159pxから0pxになりました。

4chanの工作板、ふたば料理板、sportschanとzzzchanで一覧・本文・返信・画像を確認しました。sportschanは板一覧経由と指定スレッドURL、再起動後の読込も確認しています。クリーンビルド、82件のJUnit、Lint、7世代のAPKへのCLI適用が成功しました。

詳細、入力APKのSHA-256、検証用Manager APKのSHA-256と実機検査の範囲は[検証記録](https://github.com/roflsunriz/chmate-revanced/blob/main/verification.md)を参照してください。Pixel 10aの実機UIは今回再検査していません。

配布物は`patches-1.2.5.rvp`、同SHA-256、更新情報の`patches.json`です。ChMate APK、XAPK、patch済みAPKは配布しません。
