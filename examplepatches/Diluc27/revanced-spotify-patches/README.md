# ReVanced Spotify Patches

Custom patch bundle: **Spotify Transparent Now Playing Status Bar** + Departure Mono / Geist Pixel Fonts.

## Add to ReVanced Manager

### Option 1: Direct JSON URL (recommended)
Patches tab -> edit -> + -> Enter URL:

```
https://raw.githubusercontent.com/Diluc27/revanced-spotify-patches/main/patches.json
```

### Option 2: GitHub repo URL
Patches tab -> edit -> + -> Enter URL:

```
https://github.com/Diluc27/revanced-spotify-patches
```

## Option 3: Local file
Download `patches.rvp` from [Releases](https://github.com/Diluc27/revanced-spotify-patches/releases/latest) and use "Select from storage" in Manager.
